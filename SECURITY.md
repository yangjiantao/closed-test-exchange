# Reporting a security issue

[简体中文](#安全问题报告)

Use [GitHub Security Advisories](https://github.com/yangjiantao/closed-test-exchange/security/advisories) and select **Report a vulnerability** to contact the maintainer privately. English and Chinese are welcome. Include the app and Android versions, affected behavior, and the steps needed to investigate. Keep sensitive details and personal data out of public issues.

If the report button is unavailable, [open a general issue](https://github.com/yangjiantao/closed-test-exchange/issues/new) asking the maintainer for a private contact method. Keep the report itself private.

## 安全问题报告

请前往 [GitHub Security Advisories](https://github.com/yangjiantao/closed-test-exchange/security/advisories)，选择 **Report a vulnerability** 私下联系维护者。可以使用中文或英文。请提供应用和 Android 版本、受影响的功能及调查所需的步骤。请避免将敏感细节或个人数据发到公开 Issue。

如果页面没有报告按钮，可以[开一个普通 Issue](https://github.com/yangjiantao/closed-test-exchange/issues/new)，请维护者提供私下联系渠道。报告内容请单独私下发送。
