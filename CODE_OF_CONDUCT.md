# Code of conduct

[简体中文](#行为准则)

Treat other participants with respect. Give feedback about the work, assume good faith, and accommodate people with different backgrounds, experience levels, and languages. Harassment, discrimination, threats, and sharing someone else’s personal information without permission are unacceptable on project issues and pull requests.

Flag public comments through GitHub’s reporting controls to bring them to a maintainer’s attention. Maintainers may remove content, close discussions, or limit participation in response to violations.

## 行为准则

请尊重其他参与者，就事论事，善意理解他人，照顾不同背景、经验和语言的参与者。项目的 Issue 和 PR 不接受骚扰、歧视、威胁或未经允许公开他人个人信息的行为。

如发现违规评论，请使用 GitHub 评论菜单中的举报功能反馈给维护者。维护者可根据情况删除内容、关闭讨论或限制参与。
